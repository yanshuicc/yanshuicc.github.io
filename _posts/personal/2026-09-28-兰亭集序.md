# 兰亭集序 晋 王羲之
永和九年，岁在癸（gui3）丑，暮春之初，会于会稽山阴之兰亭，修禊（xi4）事也。群贤毕至，少长咸集。此地有崇山峻岭，茂林修竹，又有清流激湍，映带左右。引以为流觞曲水，列坐其次。虽无丝竹管弦之盛，一觞一咏，亦足以畅叙幽情。是日也，天朗气清，惠风和畅。仰观宇宙之大，俯察品类之盛，所以游目骋怀，足以极视听之娱，信可乐也。

夫人之相与，俯仰一世。或取诸怀抱，悟言一室之内；或因寄所托，放浪形骸之外。虽趣舍万殊，静躁不同，当其欣于所遇，暂得于己， 快然自足，不知老之将至。及其所之既倦，情随事迁，感慨系之矣。向之所欣，俯仰之间，已为陈迹，犹不能不以之兴怀。况修短随化，终期于尽。古人云：“死生亦大矣！”岂不痛哉！

每览昔人兴感之由，若合一契，未尝不临文嗟悼，不能喻之于怀。固知一死生为虚诞，齐彭殇为妄作。后之视今，亦犹今之视昔，悲夫！故列叙时人，录其所述。虽世殊事异，所以兴怀，其致一也。后之览者，亦将有感于斯文。

# 神龙本

![Alt text](images/%E5%85%B0%E4%BA%AD%E5%BA%8F.jpg)

唐代冯承素摹本，因卷首钤有唐中宗“神龙”年号半印小玺，故称“神龙本”。其流传经历大致为：由唐宫入宋宫，入南宋高宗、理宗内府，宋理宗传驸马都尉杨镇；宋亡后，杨氏后人将其卖给元代鉴赏家郭天锡；明代入书法家丰坊万卷楼，丰坊于晚年将其摹刻上石。嘉靖年间万卷楼毁于火灾，原帖自此绝于人间，唯此石刻留存，后归天一阁收藏至今。

# 王羲之
王羲之，字逸少，约303年生，361年卒。琅琊临沂人，后来定居会稽山阴。琅琊王氏是东晋头等门第，从伯父王导是开国元勋，官至司徒，当时有“王与马，共天下”的说法。王羲之幼年丧父，由母亲和兄长带大，十三岁已因书法出名。

太尉郗鉴派人到王家选婿，其他子弟都故作矜持，只有王羲之在东床坦腹吃东西，像没听见一样。这份自然真率反而让他被选中，后来就成了东床快婿的典故。

# 右军、右军将军以及西晋行政级别
后世都叫他王右军，但这个称呼有争议。《晋书》写的是右军将军、会稽内史，可唐以前的文献多写作“右将军”。王羲之自己在《临河叙》里署右将军，何延之《兰亭始末记》、怀仁《集王圣教序》同样这么记录。

右将军和右军将军不是一回事。右将军是军号，三品（类比现在大概是副国级/正部级），属“四方将军”，可以开府置佐（类似于高配地方军政大员）。朝廷一般只授给州刺史，郡守里能拿到这个待遇的，只有会稽和丹阳二郡（类比于直辖市中的北京上海的地位）。薪俸中二千石，比一般郡守的二千石高一倍。右军将军是四品（大约是正厅级），属中央禁卫军四军，管宿卫，品阶低得多。王羲之此前做的护军将军已是三品，外放会稽内史时所授军号也在三品以上。若降成四品，史书该写“左迁”。所以，他大概率是右将军，不是右军将军。唐修《晋书》用了后一个说法，又因《王羲之传》经唐太宗亲笔审定，后世就跟着叫开了。

会稽内史这个官，职比郡守，但地位不在大州刺史之下，有点今天直辖市的意思。会稽在宁绍平原，是当时的经济中心，又是拱卫京师（建康，现江苏南京）的东南门户，还形成了独立的方镇都督区。刺史是州的最高行政长官，兼管民政军事（省长兼任省军区司令员）。东晋实行州、郡、县三级制，扬州刺史管包括会稽在内的多个郡。扬州是核心州，管京师建康和周边富庶地区，扬州刺史的分量很重。另外东晋官制的核心特点是品位与职位分离，品级越高，象征意义越强，实权反而可能越小。其中，一品太宰、太傅、太保（三公），太尉、司徒、司空，是最高荣誉，用来尊崇德高望重者。二品骠骑将军、车骑将军、卫将军、持节都督，掌握着最关键的军事力量，相当于中央军委副主席、国务委员、大军区司令。三品尚书令、尚书仆射、中书令、丹阳尹等，是行政中枢和实干核心，负责国家的日常运转和决策执行，国务院副总理/秘书长、各部部长。

# 王羲之和王述的过节
王述（字蓝田）出太原王氏，和王羲之同姓不同宗。太原王氏在北方本来地位高于琅琊王氏，但因王导南渡功大，琅琊王氏后来居上。王述年轻时并不出众，三十岁还默默无闻，被人当成痴呆。后来他像换了个人，做官清正廉洁，时人称为奇人。

王羲之一直看不上王述，偏偏王述名气越来越大。《晋书》说：“时骠骑将军王述少有名誉，与羲之齐名，而羲之甚轻之，由是情好不协。”后来王述母亲去世，王羲之接替他做会稽内史。按古礼节吊唁，“吊”应该祭奠死者，“唁”应该慰问生者。但是正史记载王羲之只吊不唁，只去吊了一次，之后就不再登门。王述每次听到角声，都以为王羲之会来看望，便洒扫庭院等着。等了几年，王羲之始终没去，王述恨透了王羲之。《晋书·王羲之传》记载，“述先为会稽，以母丧居郡境，羲之代述，止一吊，遂不重诣。述每闻角声，谓羲之当候己，辄洒扫而待之。如此者累年，而羲之竟不顾，述深以为恨”。《世说新语·仇隙》记载，“王右军素轻蓝田。蓝田于会稽丁艰，停山阴治丧。右军代为郡，屡言出吊，连日不果。后诣门自通，主人既哭，不前而去，以陵辱之。”意思是王羲之多次说要来吊丧，但却放鸽子一连几天都没去。后来终于去了，门房通报后，王述已经哭出来准备迎接，王羲之却不上前慰问，直接走了，以此羞辱王述。

后来王述做扬州刺史，成了王羲之的顶头上司（类比为在上海市划归江苏省管辖的前提下，上海市市长不服江苏省省长）。王羲之以前对宾客说：“怀祖正该做尚书，老了可做仆射。若想再做会稽内史，那就差得远了。”等王述真的显授，王羲之耻于位居其下，派使者到朝廷，请求把会稽从扬州分出来，单立越州。使者话没说好，被当时贤士讥笑。王羲之后来也愧疚，对儿子们说：“我不比怀祖差，但职位待遇差这么多，该是因为你们比不上王坦之吧。”王述的儿子王坦之是东晋名臣，年轻时名气就很大，后来官至中书令、丹阳尹，是晋孝武帝司马曜辅政重臣，声望极高。

王述到会稽巡察，审查刑政，主管官员疲于应对。王羲之觉得受辱，称病去郡。永和十一年（355），他在父母墓前立誓不再出仕：“止足之分，定之于今……自今之后，敢渝此心，贪冒苟进，是有无尊之心而不子也。”这就是“誓墓”。朝廷见他誓言恳切，也不再征召。

# 王羲之爱好与晚年
王羲之爱鹅，关于鹅王羲之又有一些名人小故事。会稽有个老太太养了只善鸣的鹅，他带亲友去看。老太太听说王羲之要来，把鹅杀了做菜款待他，王羲之为此叹了一整天。山阴道士养了一群好鹅，王羲之想买。道士说：“你替我抄一本《道德经》，整群鹅送你。”他欣然提笔，留下以书换鹅的书法小故事。史学家陈寅恪提出鹅肉解毒的观点，他认为，王羲之家族信奉天师道，有服食五石散的传统。古代医家认为，鹅肉能解五脏丹毒，可以缓解五石散带来的中毒症状。因此，王羲之爱鹅、养鹅，可能并非单纯出于艺术欣赏，而是为了食用鹅肉来解毒养生。

这里需要介绍一下五石散，它是由石钟乳、紫石英、白石英、石硫磺、赤石脂等五种矿物炼制的丹药。服用后，人会感到神明开朗，皮肤也会变得白嫩细致。五石散中的石硫磺等成分，会强烈刺激中枢神经系统，导致体温升高和异常的兴奋感，从而产生精神振奋、甚至飘飘欲仙的幻觉。这种状态本质上是神经中毒的亢奋期，类似吸毒后的短暂快感。同时五石散配方中可能含有礜石（一种砷矿物）。长期小剂量摄入砷，会导致皮肤色素沉着异常，出现白斑，同时皮肤角质层受损，变得异常敏感、脆弱，轻微摩擦就会破损。所以魏晋名士皮肤“白嫩”且穿不了硬衣服，并非因为皮肤好，而是中毒后皮肤屏障被破坏的结果。长期服用五石散会对身体造成不可逆的损伤。皇甫谧曾描述自己的症状包括，隆冬时节也得裸身吃冰、咳嗽、四肢酸重浮肿。此外，还会导致精神恍惚、发狂痴呆，以及舌缩入喉、皮肤溃烂等严重问题。许多服用者最终变得魂不守宅，血不华色，精爽烟浮，容若槁木。王羲之的信件中大量谈及自己的病情，包括全身骨痛、发烧不退、腹痛、腹泻、头痛、耳疾、脚肿等，现代学者认为这些很可能都是服散导致的慢性中毒症状。

王羲之辞官后，他和东土人士纵情山水，弋钓为娱。又和道士许迈共修服食，采药石不远千里，遍游东中诸郡，穷名山，泛沧海，感叹：“我卒当以乐死。”他在给谢万的信里写自己“率诸子，抱弱孙，游观其间，有一味之甘，割而分之”，还植桑种果，教养子孙以敦厚退让。王羲之的死因和确切年份，史书没写清。一般说他卒于升平五年（361），约五十八岁。晚年由于长期服食丹药，身体大概率受了影响。


# 兰亭集序创作背景
永和九年（353年）的兰亭雅集不是单纯的文人闲聚，那几年东晋内忧外患交织。

永和八到九年，中军将军殷浩主持北伐，想收复中原。永和九年十月，他率七万从寿春北上。前锋姚襄和殷浩不和，在山桑设伏突袭，晋军大败，丢下辎重，退保谯城。这场惨败，就在兰亭雅集之后不久。

桓温永和三年灭成汉后威名大振，手握荆州重兵，朝廷忌惮。辅政的会稽王司马昱引殷浩为心腹，让他主持北伐，想抢北伐旗帜，树立朝廷权威。王羲之夹在中间。他表面和殷浩交好，心里更敬重桓温，多次写信劝殷浩与桓温和解，反惹殷浩不快。殷浩被废后，王羲之又被看成殷浩余党，受到冷落。

兰亭雅集就在永和九年暮春，殷浩北伐还没出发，朝野已经紧张不安。王羲之召集谢安、孙绰等四十二人，在会稽山阴兰亭修禊。茂林修竹，清流激湍，曲水流觞，饮酒赋诗。他微醺中写下《兰亭序》，从仰观宇宙之大，俯察品类之盛的欢愉，转到死生亦大矣，岂不痛哉的沉痛，这里也充满了时局压在心里的影子。
