# 引子
我对Jekyll的基本样式、模板嵌套有一些修改，同时也记录自定义前端样式美化的配置。

# 多种文章风格
对于博客的布局，分别设置了文章、大纲文章、短篇窄文3种布局，layout设定分别对应article、outlined、short-article。

# 文章特性

目前文章特性自定义设置了表格特性和ai创作声明，分别对应以下代码
```
---
layout: post
title: 某篇文章
ai_assisted: false
features:
    table
    poem
    code
    math
---
```

# 代码样式

## highlight和围栏代码块的区别

两者都能渲染代码，但走的路径不同，能力上有一些细节差异。

围栏代码块是Markdown 原生能力。
````markdown
```go
func main() {
    fmt.Println("hi")
}
```
````

生成的代码如下：
```
<div class="language-go highlighter-rouge">
  <div class="highlight">
    <pre class="highlight"><code>...</code></pre>
  </div>
</div>
```
highlight 标签Jekyll的Liquid模板语法
```{% raw %}
{% highlight go %}
func main() {
    fmt.Println("hi")
}
{% endhighlight %}{% endraw %}
```

highlight 标签生成：
```
<figure class="highlight">
  <pre><code class="language-go" data-lang="go">...</code></pre>
</figure>
```

异同：
* Liquid 标签。Jekyll 会先解析 Liquid，处理Liquid代码标签逻辑再渲染 Markdown。围栏代码块不做处理直接输出。
* 围栏代码块想开行号，需要在 _config.yml 里全局设置：

```yaml
kramdown:
  syntax_highlighter_opts:
    block:
      line_numbers: true
```
或者
````markdown
```go
func main() {}
```
{: .no-lineno}
````

Liquid可以在代码块中指定
```
{% raw %}{% highlight go linenos %}
{% endhighlight %}{% endraw %}
```
