# 可逆矩阵必须是方阵？

矩阵的秩和可逆性之间的关系，一句话概括就是：

>**只有方阵才谈可逆；一个 n 阶方阵可逆，当且仅当它的秩等于 n，即满秩。**

如果秩小于 n，矩阵就**不可逆**，也叫奇异矩阵，奇异表示退化、特殊、不满足某种良好性质的含义。

可逆的定义是：存在矩阵 n，使得
$$
AB = BA = I
$$
这要求 $$A$$ 和 n 都是同阶方阵。

## 左逆/右逆

**对于非方阵没有通常意义的逆矩阵**，只有左逆或右逆的概念。左逆 B 满足 BA=I，右逆 C 满足 AC=I。左逆要求列满秩，右逆要求行满秩；非方阵只能从一边抵消，且逆不唯一。方阵可逆时，左逆=右逆=逆矩阵。

**例**：行向量 $$A = [1, 2] $$

- m=1, n=2，行满秩 r(A)=1=m，所以**有右逆**。
- 找 $$C = \begin{pmatrix}x\\y\end{pmatrix}$$ 使 $$AC = I_1 = [1]$$：
  $$
  [1,2]\begin{pmatrix}x\\y\end{pmatrix} = x+2y = 1
  $$
  有无数解，比如 \(C=\begin{pmatrix}1\\0\end{pmatrix}\) 或 \(C=\begin{pmatrix}0\\0.5\end{pmatrix}\)。  
  所以右逆存在，但**不唯一**。
- 列满秩？\(n=2\)，但 \(r=1<2\)，所以**没有左逆**。

# n 阶方阵可逆的等价条件

对于 n 阶方阵 $$A$$，下面这些说法全部等价：

| 条件 | 说明 |
|:---|:---|
| $$A$$ 可逆 | 存在 $$A^{-1}$$ |
| $$r(A)=n$$ | 秩等于阶数，即**满秩** |
| $$\det(A)\neq 0$$ | 行列式不为 0 |
| 列向量组线性无关 | n 个列向量彼此独立 |
| 行向量组线性无关 | n 个行向量彼此独立 |
| $$Ax=0$$ 只有零解 | 零空间维数为 0 |
| 对任意 n，$$Ax=b$$ 有唯一解 | 方程组总有唯一解 |
| 列空间 = $$\mathbb{R}^n$$ | 矩阵能输出整个空间 |
| 零空间 = $$\{0\}$$ | 没有非零向量被变成零 |
| 特征值全不为 0 | 若考虑特征值 |

## 一、可逆为什么一定满秩？

设 A 是 n 阶方阵，可逆意味着存在 $$A^{-1}$$，使得
$$
AA^{-1}=A^{-1}A=I
$$

**关键推理**：看齐次方程 Ax=0。  
如果 Ax=0，两边左乘 $$A^{-1}$$，得到
$$
x=A^{-1}0=0
$$
所以 \(Ax=0\) **只有零解**。

而“\(Ax=0\) 只有零解”等价于：

- \(A\) 的 \(n\) 个列向量线性无关；
- 矩阵的秩 \(r(A)=n\)，即**满秩**。

所以：可逆 \(\Rightarrow\) 满秩。

---

## 二、可逆为什么一定行列式不为 0？

还是用 \(AA^{-1}=I\)，两边取行列式：
\[
\det(A)\det(A^{-1})=\det(I)=1
\]
既然乘积等于 1，那么 \(\det(A)\) 和 \(\det(A^{-1})\) 都不可能为 0。  
所以：
\[
\det(A)\neq 0
\]

从另一个角度看：  
行列式 \(\det(A)\) 就是矩阵 \(A\) 的**最高阶（\(n\) 阶）子式**。如果可逆，则满秩，秩为 \(n\)，说明存在非零的 \(n\) 阶子式，也就是 \(\det(A)\neq 0\)。

---

## 三、反过来也成立

- 若 \(r(A)=n\)（满秩），则 \(A\) 的列向量线性无关，\(Ax=0\) 只有零解，因此 \(A\) 可逆。
- 若 \(\det(A)\neq 0\)，则可以用伴随矩阵构造逆矩阵：
  \[
  A^{-1}=\frac{1}{\det(A)}\operatorname{adj}(A)
  \]
  所以 \(A\) 可逆。

因此三者完全等价：
\[
\boxed{\text{可逆} \iff \text{满秩} \iff \det(A)\neq 0}
\]

---

## 四、直观理解

- **满秩**：矩阵的 \(n\) 个列向量没有冗余，张满整个 \(n\) 维空间，映射是一一对应的，信息不丢失。
- **行列式不为 0**：行列式表示线性变换对体积的缩放因子。如果为 0，说明空间被压缩到了更低维，信息丢失，无法还原，所以不可逆。

一句话：
> **可逆就是“没有信息丢失”，所以秩必须满，体积缩放因子（行列式）不能为 0。**


# 秩小于 n 会怎样？

如果 $$r(A) < n$$，则：

- $$\det(A)=0$$，矩阵**不可逆**；
- 列（行）向量组**线性相关**，存在冗余；
- $$Ax=0$$ 有**非零解**，零空间维数 $$n-r(A)>0$$；
- 对某些 n，$$Ax=b$$ **无解**；对有解的 n，解**不唯一**（无穷多解）；
- 列空间不能张满整个 $$\mathbb{R}^n$$。

---

## 举个例子

$$
A=\begin{pmatrix}1&2\\2&4\end{pmatrix}
$$
- 第二列是第一列的 2 倍，列向量线性相关；
- $$r(A)=1<2$$，不满秩；
- $$\det(A)=1\times4-2\times2=0$$；
- 所以 $$A$$ **不可逆**。

再如：
$$
B=\begin{pmatrix}1&2\\3&4\end{pmatrix}
$$
- 两列不成比例，线性无关；
- $$r(B)=2$$，满秩；
- $$\det(B)=1\times4-2\times3=-2\neq0$$；
- 所以 n **可逆**。
