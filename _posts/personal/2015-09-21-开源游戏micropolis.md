# 像素小游戏-Micropolis
最近玩了一款开源模拟城市的像素游戏，感觉蛮有意思的。

游戏功能设计得并不复杂，令我印象深刻的是它通过简单设计而构建出来的较为耐玩的游戏设计思路，对人口、经济、工业、犯罪率、污染等几个指标数据的设计很有感触。

![Alt text](images/Micropolis.png)

记录源码地址，后续再看吧。

源码地址:http://www.donhopkins.com/home/micropolis/

```
#编译，依赖与libxpm，yacc(依赖于m4)
sudo apt-get install libXpm-dev bison
```

# 开源模拟游戏-OpenTTD
[OpenTTD](https://github.com/OpenTTD/OpenTTD)是另一款开源模拟游戏，它照着 1995 年的《运输大亨豪华版》重新写了一遍，修铁路、跑火车、开公交、建机场，把货物和乘客从一座城运到另一座城赚钱。
