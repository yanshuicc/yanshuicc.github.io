# vim 的模式

vim有多种运行模式，不同模式下按键含义不同。

模式介绍

| 模式 | 进入方式 | 用途 |
|---|---|---|
| 普通模式 | 启动默认；按 `Esc` | 移动、删除、复制、粘贴 |
| 插入模式 | `i` `I` `a` `A` `o` `O` | 输入文字 |
| 可视模式 | `v` `V` `Ctrl-v` | 选择文本块 |
| 命令模式 | `:` `/` `?` | 执行命令、搜索 |
| 替换模式 | `R` | 覆盖输入 |
| 终端模式 | `:terminal` | 在 vim 内运行终端 |

按 `Esc` 可从大多数模式回到普通模式。

# 搜索与替换

## 基本替换

| 命令 | 说明 |
|---|---|
| `:s/old/new/` | 当前行替换第一个 |
| `:s/old/new/g` | 当前行全部替换 |
| `:%s/old/new/g` | 全文替换 |
| `:%s/old/new/gc` | 全文替换并确认 |
| `:n,m s/old/new/g` | 第 n 到 m 行替换 |
| `:.,$s/old/new/g` | 当前行到文件末尾替换 |
| `:%s/old/new/gi` | 忽略大小写替换 |

## 常用替换示例

所有 `{` 后面添加换行和空格：

```vim
:%s/{/{\r /g
```

所有 `}` 前后添加换行：

```vim
:%s/}/\r}\r /g
```

删除行尾空格：

```vim
:%s/\s\+$//e
```

删除空行：

```vim
:g/^$/d
```

统计匹配次数：

```vim
:%s/pattern//gn
```

# 配置文件 `.vimrc`

下面是一份较完整的 `.vimrc` 示例，可按需删减。

```vim
" ===== 编码 =====
set encoding=utf-8
set fileencodings=utf-8,ucs-bom,gb18030,gbk,gb2312,cp936

" ===== 文件类型检测 =====
filetype on
filetype indent on
filetype plugin on
filetype plugin indent on

" ===== 显示 =====
set number                  " 显示行号
set relativenumber          " 显示相对行号
set ruler                   " 显示标尺
set cursorline              " 高亮当前行
set showcmd                 " 显示命令
set showmatch               " 匹配括号
set laststatus=2            " 总是显示状态栏
set scrolloff=5             " 光标距离顶部/底部保留 5 行
set wildmenu                " 命令行补全菜单

" ===== 缩进 =====
set tabstop=2               " Tab 显示为 2 个空格
set shiftwidth=2            " 自动缩进 2 个空格
set expandtab               " Tab 转空格
set autoindent              " 自动缩进
set smartindent             " 智能缩进

" ===== 搜索 =====
set hlsearch                " 高亮搜索
set incsearch               " 增量搜索
set ignorecase              " 忽略大小写
set smartcase               " 智能大小写

" ===== 编辑 =====
set backspace=indent,eol,start
set mouse=a                 " 启用鼠标
set clipboard=unnamed       " 共享系统剪贴板，Linux 可用 unnamedplus
set backup                  " 启用备份
set backupext=~             " 备份后缀
set backupdir=~/.vim/backup//
set directory=~/.vim/swap//
set undofile                " 持久化撤销
set undodir=~/.vim/undo//

" ===== 折叠 =====
set foldenable
set foldmethod=indent
set foldlevel=99

" ===== 映射 =====
inoremap jk <Esc>           " 插入模式快速退出
nnoremap <leader>w :w<CR>   " 保存
nnoremap <leader>q :q<CR>   " 退出
nnoremap <leader>h :noh<CR> " 取消搜索高亮
```

常用设置说明：

| 设置 | 作用 |
|---|---|
| `set number` | 显示绝对行号 |
| `set relativenumber` | 显示相对行号，方便跳转 |
| `set cursorline` | 高亮当前行 |
| `set expandtab` | Tab 转空格 |
| `set tabstop=2` | Tab 宽度 |
| `set shiftwidth=2` | 自动缩进宽度 |
| `set hlsearch` | 搜索高亮 |
| `set incsearch` | 边输入边搜索 |
| `set ignorecase` | 忽略大小写 |
| `set smartcase` | 有大写时区分大小写 |
| `set clipboard=unnamed` | 使用系统剪贴板 |
| `set foldmethod=indent` | 按缩进折叠 |

# 插件管理

最简单的插件管理器是 `vim-plug`。

安装：

```bash
curl -fLo ~/.vim/autoload/plug.vim --create-dirs \
  https://raw.githubusercontent.com/junegunn/vim-plug/master/plug.vim
```

在 `.vimrc` 中添加：

```vim
call plug#begin('~/.vim/plugged')

Plug 'preservim/nerdtree'           " 文件树
Plug 'tpope/vim-commentary'         " 快速注释
Plug 'junegunn/fzf', { 'do': { -> fzf#install() } }
Plug 'junegunn/fzf.vim'             " 模糊搜索
Plug 'ycm-core/YouCompleteMe'       " 自动补全

call plug#end()
```

然后在 vim 中执行：

```vim
:PlugInstall
```

常用插件：

| 插件 | 作用 |
|---|---|
| `nerdtree` | 文件树 |
| `vim-commentary` | `gcc` 注释当前行 |
| `fzf.vim` | 模糊搜索文件、缓冲区 |
| `YouCompleteMe` | 代码补全 |
| `vim-airline` | 状态栏美化 |
| `gruvbox` | 配色主题 |

# 总结

vim 的学习曲线较陡，但多用自然就会熟练，掌握常用命令后编辑效率会显著提升。先从移动、编辑、搜索替换、保存退出开始，逐步加入分屏、宏、寄存器、插件和自定义配置。把常用的 `.vimrc` 配置保存下来，换机器时直接复用即可。
