# 开源模拟游戏-OpenTTD
[OpenTTD](https://github.com/OpenTTD/OpenTTD) 是另一款开源模拟游戏，它照着 1995 年的《运输大亨豪华版》重新写了一遍，修铁路、跑火车、开公交、建机场，把货物和乘客从一座城运到另一座城赚钱。

# 像素工厂-Mindustry
[Mindustry](https://github.com/Anuken/Mindustry) 是一款融合了工厂自动化、塔防和即时战略（RTS）元素的独立游戏。它最初是开发者 Anuke 在 2017 年的一场 Game Jam 中，用 72 小时制作的原型，之后持续更新发展成为一款内容极为丰富的开源游戏。其核心循环是建造供应链以支撑防御与进攻，不像传统塔防那样只需放置炮塔，它需要搭建一套复杂的自动化工业体系来维持运转。

游戏覆盖 Windows、macOS、Linux、Android 和 iOS 等多个平台，并且支持跨平台多人合作与对战。

# 公元0年-0 A.D.
[0 A.D.](https://github.com/0ad/0ad) 是一款古代战争题材即时战略（RTS）游戏，由全球志愿者团队 Wildfire Games (WFG) 开发，旨在让玩家重现或改写公元前 500 年至公元 500 年的西方文明历史。

游戏提供了 14 个独特的古代文明供玩家选择，包括雅典、斯巴达、罗马、迦太基、波斯、印度等。每个文明在单位、建筑和科技树上都各具特色。核心玩法有：
* 领土系统：建造建筑来扩张你的领土边界，控制资源点
* 对战系统：排列对战阵型，如马其顿方阵（Phalanx）或罗马龟甲阵（Testudo）
* 不同的游戏模式：征服模式、弑君模式、奇观胜利等

游戏使用名为 Pyrogenesis 的自研游戏引擎，引擎核心由 C++ 编写以保证性能，游戏逻辑、AI 和界面交互则大量使用 JavaScript 来驱动，便于修改和扩展。

# Battle for Wesnoth（韦诺之战）
[Battle for Wesnoth](https://github.com/wesnoth/wesnoth) 是一款以高奇幻为主题的开源回合制策略游戏，由美国开发者 David White 等人于 2003 年首次发布。游戏以架空奇幻世界 Irdya 为背景，采用六边形网格地图设计，包含 16 个官方战役（超过 200 个场景）及大量玩家自制战役。

游戏提供六个主要派系供玩家选择，涵盖人类、精灵、矮人、兽人、亡灵等种族，拥有超过 200 种单位。核心机制围绕地形适应性和昼夜时段立场（守序、混沌、中立、边缘）展开——不同种族在白天或黑夜中的战斗力会有显著差异，需要据此制定策略。玩家通过控制村庄获取金币来维持军队开支，单位可通过战斗升级并继承至后续场景。

游戏支持单机、局域网及在线多人对战，提供 50 多张多人地图，并支持包括中文在内的 40 多种语言。作为自由游戏联盟成员，游戏基于 GPL 协议发布，拥有活跃的模组社区，用户自制内容可从官方服务器下载，优秀作品甚至会被纳入官方发布。

# Tux 开的卡丁车-SuperTuxKart
[SuperTuxKart](https://github.com/supertuxkart/stk-code) 是一款开源三维街机赛车游戏，目标是为所有年龄段的玩家带来比真实卡丁车更纯粹的乐趣。游戏以 Linux 吉祥物企鹅 Tux 为主角，角色阵容还包括 GIMP 的吉祥物 Wilber、OpenBSD 的 Puffy、KDE 的 Konqi 等众多开源项目的吉祥物。

游戏核心玩法类似《马里奥赛车》，玩家可在比赛中使用冰冻射线等道具干扰对手，还设有足球模式和自定义赛道功能。游戏提供故事模式（打败反派 Nolok，拯救导师 Gnu）、计时模式、锦标赛以及本地最多 8 人同屏对战和在线多人模式。目前已包含 21 条原创赛道，下载量超过 500 万次。

SuperTuxKart 采用 C++ 和 OpenGL/OpenGL ES 技术构建，支持 Linux、Windows、macOS 及 Nintendo Switch 平台，代码遵循 GNU GPL 协议。玩家可通过 Blender 工具创作自己的角色和赛道并分享至社区。

# Minetest（Luanti）
[Minetest](https://github.com/minetest/minetest)（现已更名为 **Luanti**）是一款开源体素沙盒游戏与游戏开发平台，由 Perttu Ahlola（别名“celeron55”）于 2010 年创建，灵感来源于 Infiniminer 和 Minecraft。玩家可以在三维开放世界中创建和销毁各种方块，支持生存模式和创造模式，同时具备多人联机、动态光照和“无限”地图生成功能。

Luanti 的最大特色在于它是一个游戏平台而非单一游戏。引擎本身只提供基础的体素渲染和网络功能，游戏玩法通过 Lua API 由“子游戏”定义。ContentDB 上已有超过 3100 个开源模组可供使用和改编。地图尺寸达到 62,000 × 62,000 × 62,000 个方块，支持 Windows、macOS、Linux、BSD 和 Android 系统。引擎基于 LGPL 协议发布，完全开源透明。

# Endless Sky
[Endless Sky](https://github.com/endless-sky/endless-sky) 是一款 2D 太空探索、贸易与战斗游戏，风格类似经典的 Escape Velocity 系列。玩家从一艘最基础的飞船起步，通过贸易、运送乘客、完成各种任务来赚钱，逐步升级武器、引擎和飞船，最终拥有一支属于自己的舰队。

游戏设定在一个人口稠密的银河系中，人类空间由约 200 个星系通过超空间链路连接。玩家可以选择成为商人、海盗猎人、赏金猎人，也可以深入未知空间寻找外星文明。游戏包含一条完整的主线剧情——参与一场重塑人类空间的叛乱，以及大量支线任务。约 70 种不同型号的飞船可供购买，从大型货轮到强大战舰再到灵巧的侦察舰。游戏还拥有丰富的装备系统，玩家需要在能源、散热和空间之间做出权衡。

Endless Sky 完全免费开源，支持 Windows、macOS 和 Linux 平台，设计上尽可能便于社区创作新内容，目前已有多个其他故事线正在开发中。

# Xonotic
[Xonotic](https://gitlab.com/xonotic/xonotic) 是一款快节奏的竞技场式第一人称射击游戏（FPS），衍生自另一款开源 FPS 游戏 Nexuiz，由从 Nexuiz 社区分裂出来的 Xonotic 团队负责开发。游戏基于源自 Quake 引擎的 DarkPlaces 引擎，设计灵感来自《雷神之锤》和《虚幻竞技场》。

Xonotic 主打经典死亡竞赛和竞技场玩法，强调流畅的移动机制和丰富的武器选择。游戏包含多种武器，每种都有主副两种开火模式，配合冲刺、跳跃等移动技巧，形成极高的操作上限。游戏完全免费，支持 Windows、macOS 和 Linux 平台，拥有活跃的社区服务器和定期锦标赛。

# Veloren
[Veloren](https://github.com/veloren/veloren) 是一款开源多人体素角色扮演游戏（RPG），使用 Rust 语言编写。游戏从 2018 年中开始开发，灵感来源于《Cube World》《矮人要塞》《塞尔达传说：旷野之息》和《Minecraft》。玩家可以在广阔的开放世界中探索、战斗、制作和建造，创建高度自定义的角色，体验类似《旷野之息》的冒险感。

项目由约 20 名活跃开发者以及另外 20 名艺术家、作家、设计师和作曲家共同贡献，已有超过 150 人参与过该项目。游戏采用社区原创的图形、音乐等素材，基于 GPL 3.0 协议发布，目前处于 beta 阶段但已可游玩，支持 Windows、Linux 和 macOS。

# Shattered Pixel Dungeon
[Shattered Pixel Dungeon](https://github.com/00-Evan/shattered-pixel-dungeon)（破碎的像素地牢）是一款传统 Roguelike 地牢探索 RPG，由开发者 Evan Debenham 基于 Watabou 于 2012 年发布的开源游戏《像素地下城》的源代码开发，项目于 2014 年启动，旨在对原版进行全面改进和扩展。

游戏上手容易但精通很难。每次游戏都是独一无二的挑战：6 位独特英雄，每位拥有 2 个子类、3 个终局能力和超过 25 种天赋；随机生成的关卡包含 5 个区域、26 个楼层、超过 100 种房间类型及数万亿种布局可能；超过 300 种道具、60 多种敌人类型、30 种陷阱和 10 个首领。游戏还包含炼金系统和地形策略要素。

游戏完全免费开源，不含广告与内购，支持社区模组开发与多语言翻译，更新频率约为每月一次。支持 Android、iOS、Steam 等平台，全平台销量超过 10 万份。

# OpenRA
[OpenRA](https://github.com/OpenRA/OpenRA) 是一个开源即时战略（RTS）游戏引擎，使用 C# 编写，基于 SDL 和 OpenGL，专门用于重制和现代化 Westwood 的经典 RTS 游戏。它支持《命令与征服：红色警戒》《命令与征服：泰伯利亚黎明》和《沙丘 2000》三款经典作品。

OpenRA 并非简单的复刻，而是围绕现代 RTS 体验重新设计了游戏机制，加入了攻击移动、单位经验、战争迷雾等现代功能，同时保留了经典玩法的核心魅力。游戏支持完整的模组系统和自定义地图，内置 Mod SDK 允许玩家创建全新的 RTS 游戏。多人模式支持在线对战和自定义地图，社区定期举办锦标赛。游戏原生支持 Windows、macOS 和 Linux 平台，完全开源，开发过程公开透明。

# Cataclysm: DDA
[Cataclysm: Dark Days Ahead](https://github.com/CleverRaven/Cataclysm-DDA) 是一款回合制生存 Roguelike 游戏，背景设定在一个后末日世界中。游戏世界是程序生成的、持久化的、严酷的，玩家需要在其中挣扎求生。从死去的文明遗迹中搜刮食物、装备，或者——如果你运气好的话——找到一辆油箱满满的汽车，逃离这片地狱。

游戏的深度惊人。你需要管理饥饿、口渴、温度、伤口感染、精神健康等无数生存指标。敌人种类从僵尸、巨型昆虫到杀手机器人乃至更诡异可怕的存在。游戏采用回合制玩法和类似 RPG 的技能成长系统，是现代传统 Roguelike 的典范之作。

游戏支持 Windows、macOS、Linux 及 Android 系统（iOS 版本已不再维护），提供多种语言版本，完全开源免费。
